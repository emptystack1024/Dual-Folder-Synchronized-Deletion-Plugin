# Dual-Folder-Synchronized-Deletion-Plugin(同步文件查看器)
同时操作两个文件夹，并且对两个文件夹同步删除操作


## 项目简介

同步文件查看器是一个用Python开发的图形界面工具，专为文件同步管理而设计。该工具允许用户同时查看和管理两个文件夹中的内容，提供直观的文件对比和同步删除功能。

## 主要功能

- **双文件夹视图**：同时显示两个文件夹的内容，方便对比
- **同步滚动**：两侧视图同步滚动，便于文件对比
- **文件预览**：自动生成文件和文件夹的缩略图预览
- **多选操作**：支持使用Shift和Ctrl键进行多选
- **同步删除**：删除一侧文件时，可同时删除另一侧的相同文件
- **批量删除**：支持选择多个文件进行批量删除操作


## 运行方法

运行主程序：
```bash
python sync_file_viewer.py
```

## 使用说明

1. 启动程序后，点击"浏览..."按钮选择要比较的两个文件夹
2. 点击"加载文件"按钮加载两个文件夹的内容
3. 使用以下方式选择文件：
   - 单击：选择单个文件
   - Ctrl+单击：选择/取消选择多个文件
   - Shift+单击：选择一个范围的文件
4. 点击单个文件下方的"删除"按钮可删除该文件及其在另一文件夹中的副本
5. 选择多个文件后，点击顶部的"删除选中"按钮可批量删除所选文件

## 常见问题

1. **问题**：程序无法启动
   **解决方案**：确保已安装Python和所需的依赖库

2. **问题**：无法显示图片缩略图
   **解决方案**：确保已正确安装Pillow库

3. **问题**：在Linux系统上滚动不同步
   **解决方案**：程序已适配Linux的滚动事件，如仍有问题，请检查系统配置
